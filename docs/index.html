常见问题

收费吗？会看广告吗？

完全免费，无广告、无会员、无注册。软件运行在你的电脑上，没有任何需要你付费解锁的功能。

支持哪些网站？

跟随 yt-dlp 的站点库（上千个，含 YouTube、哔哩哔哩、抖音、TikTok、X、Instagram 等），并随组件热更新持续跟进站点变化。个别站点的可用性取决于目标网站的规则与你的网络环境。

需要自己安装 yt-dlp 或 Python 吗？

不需要。官方二进制已内置在安装包中，并在发布时逐一校验；更新时通过热更新通道自动跟进，无需重装软件。

能下载播放列表或整个频道吗？

当前版本只处理单条链接，播放列表与频道批量下载在计划中，尚未上线。

我的数据和隐私在哪？

解析、下载、任务队列全部在本地内存与你的磁盘上，没有账号体系，不上传任何观看或下载记录；软件只在检查更新时访问版本发布服务器。
